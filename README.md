# 모아장부 웹앱 (지인 공유용)

내 휴대폰에만 저장되는 가계부예요. 로그인과 초대가 없고, 링크를 받은 사람마다 자기 휴대폰에 자기 장부가 따로 생겨요. 장부 데이터는 어디로도 전송되지 않아서 만든 사람도 볼 수 없어요.

## 폴더 안 파일

| 파일 | 역할 |
| --- | --- |
| index.html | 앱 본체 |
| manifest.webmanifest | 홈 화면에 추가할 때 쓰는 앱 이름과 아이콘 정보 |
| sw.js | 인터넷이 없어도 열리게 하는 파일 |
| icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png | 앱 아이콘 |

7개 파일을 모두 함께 올려야 해요. 이 폴더는 PAMO 소스(`source`)와 분리되어 있어요.

## 주소와 배포

- **앱 주소: https://moajangbu.pages.dev** (Cloudflare Pages, 무료)
- 이 저장소의 `main` 브랜치와 연결돼 있어서, `main`에 올리면 1분 안에 자동으로 배포돼요. 빌드 단계는 없어요(Framework preset: None, 출력 폴더: `/`).
- 배포 기록과 설정: Cloudflare 대시보드 → Workers & Pages → `moajangbu`
- 예전 주소 `https://channnn1227.github.io/moajangbu/`는 이전 기간에만 열어 둬요. 여기서 앱을 열면 새 주소로 옮기라는 안내가 떠요(`index.html`의 `NEW_HOME`). 지인들이 다 옮기면 저장소를 비공개로 바꾸고, 그러면 예전 주소는 멈춰요.

## 고친 버전 올리기

1. 바뀐 파일을 `main`에 올립니다(커밋·push, 또는 저장소에서 **Add file** → **Upload files**).
2. `sw.js` 첫 부분의 `VERSION = "moajangbu-v2"`를 `v3`, `v4`처럼 올려서 같이 올립니다. 그래야 이미 설치한 사람들도 새 버전을 받아요.
3. 사용자 장부 데이터는 그대로 남아요.

## 받는 사람 안내 (그대로 복사해서 보내도 돼요)

> 모아장부 링크예요: https://moajangbu.pages.dev
> 아이폰: Safari로 열고 공유 버튼 → 홈 화면에 추가 → '웹 앱으로 열기' 켜고 추가
> 갤럭시: 삼성 인터넷이나 Chrome으로 열고 메뉴 → 홈 화면에 추가
> 장부는 내 휴대폰에만 저장돼요. 자산 탭 → 백업에서 2주에 한 번쯤 백업 파일을 저장해 두세요.

## 알아둘 점

- 휴대폰을 바꾸거나 브라우저 데이터를 지우면 장부가 사라져요. 백업 파일로 옮겨야 해요.
- 같은 사람이라도 Safari와 홈 화면 앱, 휴대폰과 PC의 장부는 서로 따로예요.
- 장부는 주소별로 저장돼요. 주소가 바뀌면 예전 주소에서 백업 파일을 저장하고 새 주소에서 불러와야 해요.
- 신한카드·신한은행 문자는 자동으로 읽어요. 다른 카드사 문자와 캡처 읽기는 이 버전에는 없어요(claude.ai 버전에만 있음).
- 통계 탭: 돈의 흐름(수입 → 지출 카테고리·남은 돈), 이번 달·지난달 누적 지출 비교, 카테고리 도넛을 보여줘요.
- 인사이트: 예산 초과 예상, 평소보다 많이 쓴 카테고리, 다가오는 정기 결제, 구독 금액 변동, 저축률 변화를 달력·통계 탭 위에 알려줘요. ✕로 닫으면 그 안내는 다시 나오지 않아요.
- 정기 결제(자산 탭): 3달 넘게 비슷한 날·비슷한 금액으로 나간 결제를 자동으로 모아요. 달력에는 예정일에 점이 찍혀요.
- 자동 분류 규칙(자산 탭 → 설정): 가맹점·금액·결제 수단 조건으로 카테고리와 지출 성격을 정해요. 규칙과 정기 결제 설정은 백업 파일에 함께 들어가요.
- 통계 탭의 PAMO 월간 요약 파일은 PAMO-Household의 `monthly_summary_YYYY-MM.json`과 같은 형식이에요.
